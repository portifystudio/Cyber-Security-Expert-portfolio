# CyberSec - Elite Cybersecurity Portfolio Template

![CyberSec Preview](assets/og-image.png)

A premium, high-performance cybersecurity expert portfolio template designed for elite security professionals. Featuring a hacker-inspired aesthetic with modern glassmorphism, terminal animations, and a matrix-style background.

## 🚀 Live Demo
Ready for production and optimized for Vercel deployment.

## 🛠️ Tech Stack
*   **Core:** Semantic HTML5, CSS3 (Modern Vanilla), JavaScript (ES6+)
*   **Animations:** [GSAP](https://greensock.com/gsap/) (ScrollTrigger), [Anime.js](https://animejs.com/)
*   **Icons:** Font Awesome 6
*   **Fonts:** Tajawal, Fira Code, Orbitron (via Google Fonts)
*   **Design:** Custom Dark Theme, Glassmorphism, Responsive Grid/Flexbox

## ✨ Features
*   **Interactive Terminal:** Custom initialization loader with security protocol simulation.
*   **Matrix Background:** Dynamic canvas-based matrix rain effect.
*   **Security Operations Slider:** Interactive showcase of expertise.
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop.
*   **SEO Optimized:** Pre-configured meta tags, OG tags, and accessibility features.
*   **RTL Support:** Built-in direction toggle for multi-language support.
*   **Performance:** Lightweight assets and optimized code for fast loading.

## 💻 Installation
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/portifystudio/cybersecurity-expert-portfolio.git
    ```
2.  **Navigate to the project:**
    ```bash
    cd cybersecurity-expert-portfolio
    ```
3.  **Open `index.html` in your browser** or use a Live Server extension in VS Code.

## 🌐 Deployment (Vercel)
Deploying this project to Vercel is seamless:
1.  Push your code to a GitHub repository.
2.  Log in to [Vercel](https://vercel.com).
3.  Click **"New Project"**.
4.  Import your GitHub repository.
5.  Vercel will automatically detect the static project. Click **"Deploy"**.
